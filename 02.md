### conjugate prior:
prior that makes the posterior dis to *stay in the same family as the pior*

ex.
1. binomial likelihood, choose $\operatorname{Beta}(a,b)$ to be prior
2. $\operatorname{Gamma}(a,b)$ for poisson
3. gamma for gamma
4.  * Normal prior $N(b,d^2)$ for normal likelihood 

When data comes from exp family:
$f(x\mid\theta) = h(x)g(\theta)\exp\{t(x)c(\theta)\}$

then the conjugate prior is easy to be found

for normal case, Posterior precision = prior precision ($1/d^2$) + $n \times$ data precision ($1/\sigma^2$)
