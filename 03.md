# Part 4 Now how to get samples -> Rejection sampling !

## why know shape of $f(x)$ but still hard to sample from it
can calculate density height != can sample from it
ex. $f(x) \propto e^{-x^4+x^2}$

general idea is inverse CDF sampling
$U \sim U(0,1)$, then $X = F^{-1}(U)$
problem is $F$ or $F^{-1}$ may be hard to calculate

## how Rejection sampling works

condition : only need target $f(x)$ up to proportionality, no need normalized

step:
- find proposal $g(x)$ easy to sample (and better close to shape of f , so that k can be small (P(acceptance) 正比於 1/K)  , acceptance 高一點才不會浪費proposal  ), and constant $K$ s.t. $f(x) \leq K g(x)$ for all $x$
- sample  x* from $g$,  and  method 1: accept with probability $f(x)/(K g(x))$  ; method 2. : draw y* from U(0 , Kg(x*)) then accept x* if y* <= f(x*)


Bayesian case: $\pi(\theta\mid y) \propto L(y\mid\theta)\pi(\theta)$
RHS can calculate -> know relative shape of posterior
normalising constant unknown is fine, as long as we can find above envelope

## when to use
hard to sample target directly, but can calculate $f(x)$ and find easy proposal $g(x)$ with finite $K$
-> rejection sampling is one option

- normalising constant can be known or unknown, both fine
- not the only method, no need to wait until MCMC fails
- efficiency depends on how tight envelope is

let $p(x)=f(x)/Z$, $Z=\int f(x)\,dx$
acceptance rate $= Z/K$
envelope too loose -> reject many candidates -> waste samples

## relation to Monte Carlo integration
recall use sample average to estimate integral
$\int h(x)p(x)\,dx \approx \frac{1}{N}\sum_{i=1}^N h(X_i)$, where $X_i \sim p$

rejection sampling -> get samples
Monte Carlo integration -> use samples to estimate integral
can sample $p$ directly? still can do Monte Carlo integration
